# HelpSupport — 治疗支持 App 需求说明（v1.1）

面向医院内小规模部署（≈100 并发），为患者提供日常支持和行为改变辅助的移动应用。

> **目标市场**：海外（界面英文）
> **设计参考**：Keep 风格 —— 卡片式、简洁、激励感
> **平台**：iOS & Android

---

## 1. 背景与目标

**目标**：为吸毒等行为改变场景提供一个集 AI 聊天干预、同伴支持、个人记录、治疗计划与教育资源于一体的移动应用。

**使用场景**：院内门诊 / 随访。医生/治疗师可配置计划，患者在院内及出院后跟随执行。

---

## 2. 角色与权限

### 2.1 患者（默认角色）

- 使用 AI 聊天会话
- 查看与编辑每日任务
- 接收通知
- 在社区发帖与互动（可匿名化昵称）
- 编辑个人资料
- 撰写私密日记（仅设备本地存储）

### 2.2 临床人员 / 治疗师（医院内部）

- **注册**：需上传资格证明 → 管理员审核 → 通过后方可激活账号。发帖会标注"医生"徽章
- 配置治疗计划（时间线卡片）
- 下发 / 审核每日任务模板
- 查看患者同意后开放的数据仪表（非原文日记，聚合概览）
- 社区内容审核

---

## 3. 功能模块

### 3.1 AI 互动聊天（Chat Window）

与院内部署的 AI 进行对话干预（全部是 AI）；支持文字与语音输入；生成可执行的任务与建议。

#### 三个聊天模式

| 模式         | 名称              | 说明                                                                                           |
| ------------ | ----------------- | ---------------------------------------------------------------------------------------------- |
| **心理医生** | AI Therapist      | 专业心理治疗对话模式                                                                           |
| **心理陪伴** | AI Companion      | 使用前患者先给出一段描述（提示可让 AI 扮演男友、女友、动物等，并给出要求），描述会传输到服务器 |
| **模拟病人** | Simulated Patient | 与心理陪伴功能完全一致                                                                         |

- 每个模式在进入聊天前都有**介绍页面**
- 心理陪伴的用户描述（角色设定 prompt）上传至服务器

#### 文本会话

- 支持 Markdown 渲染（列表、粗体、链接）
- 消息撤回（本地 UI 层面）与复制
- 多轮对话上下文保留，可按会话归档
- 会话命名：「第一次访问」「第二次访问」等（自动递增）
- 所有对话历史保存并上传到服务器，患者也可回顾

#### 语音与视频输入

- **实时通话模式**：打开麦克风 + 可选摄像头（iOS/Android 原生），与 AI 实时对话
- **按住录音模式**：长按/点击录音，非实时对话（类似微信语音消息）
- **AI 语音回复**：AI 同时返回文本和语音，用户可选择展开文本或只听语音（微信风格）
- 总结：类似微信对话体验 —— 可语音视频通话、可打字对话、打字对话支持语音输入

#### AI 任务下发

- AI 可在对话中返回**任务卡片**：`{ date, start_time, end_time, title, description, reminders: [T-30m, on-time], source: "chat" }`
- 任务卡片在一次访问结束后生成
- 任务可编辑到患者的任务日历中

#### AI 陪伴离线模式

- 支持**离线**和**在线**两种模式，患者自行选择
- 离线模式：数据存储在设备本地，使用 **WebLLM**（基于 WebGPU）在设备端运行模型
- 患者可下载/删除不同的模型（WebLLM 支持多种开源模型）
- WebLLM 天然跨平台，兼容 Android 和 iOS

---

### 3.2 社区（Community）

受控的同伴互助区，类似论坛社区体验，设计参考 **Keep 社区**。

#### 帖子

- 内容：纯文本 / 图片 / 链接
- 标签：求助、经验、复发反思、里程碑等

#### 互动

- 评论、点赞、收藏、关注标签

#### 匿名策略

- 默认展示昵称 + 可选匿名开关
- 可一键隐藏历史

#### 审核（AI + 人工）

- **关键词预审**：自杀/自残/违法等敏感词触发提醒与引导求助
- **人工审核通道**：医院人员审核
- **举报与封禁机制**

---

### 3.3 个人用户资料（Profile）

#### 患者资料

- 昵称、年龄段、性别（可选）
- 吸毒基线：频率、量级（可选）
- 触发因素、目标（完全戒断/减少，可选）
- 历史记录
- 系统设置

#### 医生资料

- 需**上传资格证明** → 管理员审核 → 通过后才能注册
- 医生发帖有特别标注（"医生"徽章）

#### 隐私设置

- 社区可见范围：公开 / 半公开 / 匿名
- 日记是否可被模型摘要参与进度面板（默认允许，仅聚合）

#### 验收标准

- 信息编辑后即时生效
- 敏感字段保存前二次确认

---

### 3.4 日记（Journal）

患者用来记录自己的经历或其他内容。**数据保存在用户设备里，不能上传到服务器。**

#### 展示方式（二选一）

- **日历视图**：在日历上展示日记条目
- **列表视图**：按 1、2、3、4… 编号展示不同的日记

---

### 3.5 时间线卡片 / 治疗计划与奖励分数（Timeline Card）

#### 治疗计划结构

- 阶段名称、起止日期、阶段目标
- 关键任务（支持重复）、复诊节点、评估量表
- AI 返回结构化任务格式：

```json
{
  "date": "2025-03-15",
  "start_time": "09:00",
  "end_time": "09:30",
  "title": "Morning Meditation",
  "description": "10-minute guided breathing exercise",
  "reminders": ["T-30m", "on-time"],
  "source": "chat | timeline | template"
}
```

#### 日历视图

- 任务卡片展示时间段、优先级、来源
- 支持拖拽改时间、点击编辑内容
- 批量操作：完成 / 跳过 / 延期
- 患者可对提醒时间做微调

#### 奖励分数系统

- 完成一次任务 → 获得分数
- **等级系统**：分数累积到阈值自动升级
- **里程碑回忆录**：升级时 AI 生成回忆录视频（使用用户的交流历史、发帖信息等），视频返回给用户
- **奖励兑换**：分数到一定程度可免费预约真人医生

#### 系统通知

- 与手机原生通知集成（iOS APNs / Android FCM）
- `start_time` 前可配置 T-5 / T-10 / T-30 分钟提醒
- 锁屏横幅 + 点击直达任务详情
- 失败重试与离线队列（网络恢复后下发）

#### 验收标准

- 能将阶段任务批量写入「每日任务日历」（包括 AI 在访问后返回的任务）
- 变更后同步更新相应提醒
- 所有数据后台都能看见

---

### 3.6 教育素材（Material）

#### 内容类型

- 文章、视频、音频、小册（PDF / ePub）

#### 分类（可后续动态编辑）

- 入门
- 动机与认知
- 应对技能
- 复发预防
- 家属指南

#### 功能

- 可离线缓存
- 进度记忆（上次看到哪里）
- 用户可上传**私人素材**（仅自己可见，不能上传到公开）

---

### 3.7 娱乐内容（Entertainment）

- 书籍、电影、音乐
- 分类浏览、收藏、应用内消费

---

### 3.8 真人医生预约（Appointment）

- 参考**壹心理**预约系统
- 预约后同步更新到日历
- 预约详情关联治疗时间线

---

### 3.9 账号与登录（Account）

#### 注册 / 登录

- 本地注册：手机号或邮箱 + 密码
- 忘记密码 → 邮箱/手机号重置链接

#### 会话管理

- 单端在线限制（可选）
- 支持手动下线其他设备

#### 合规

- 隐私条款与同意书 —— **首次登录必读**

---

## 4. 非功能性需求

### 性能

- 院内小规模部署，同时在线 ≈100 用户
- 移动端 iOS 和 Android
- 弱网自适应与重试

### 安全与隐私

- 传输：HTTPS / TLS
- 敏感数据加密存储（日记、健康相关字段）
- 日记数据：仅设备本地存储，不上传服务器
- 建议参考 HIPAA / GDPR 规范处理健康数据

## 5. 项目结构

```
helpsupport/
├── helpsupport-frontend/   # 患者端移动应用（UniApp + Vue 3）
├── saiadmin-artd/          # 管理后台（Art Design Pro + Element Plus）
├── server/                 # 后端 API（Webman PHP + ThinkORM）
├── AGENTS.md               # AI IDE 项目指南
└── PRD.md                  # 本文档
```

| 模块             | 前端 (helpsupport-frontend) | 管理后台 (saiadmin-artd) | 后端 (server)           |
| ---------------- | --------------------------- | ------------------------ | ----------------------- |
| 3.1 AI 聊天      | `src/pages/chat/`           | 聊天日志审阅             | Chat API + AI 代理      |
| 3.2 社区         | `src/pages/community/`      | 内容审核                 | 社区 CRUD + 审核 API    |
| 3.3 个人资料     | `src/pages/profile/`        | 用户管理                 | 用户 API                |
| 3.4 日记         | `src/pages/journal/`        | —（仅设备本地）          | —（仅设备本地）         |
| 3.5 时间线与奖励 | `src/pages/timeline/`       | 计划模板、进度仪表盘     | 任务/计划 API、奖励引擎 |
| 3.6 教育素材     | `src/pages/materials/`      | 内容管理                 | 素材 CRUD API           |
| 3.7 娱乐内容     | `src/pages/entertainment/`  | 内容管理                 | 媒体 CRUD API           |
| 3.8 医生预约     | `src/pages/appointment/`    | 医生排班管理             | 预约 API                |

## 6. 技术栈总结

| 层级       | 技术方案                                                       |
| ---------- | -------------------------------------------------------------- |
| 移动端应用 | UniApp + Vue 3 + TypeScript + Vite 5 + UnoCSS + wot-design-uni |
| 管理后台   | Vue 3 + Art Design Pro + Element Plus + Tailwind CSS 4         |
| 后端服务   | Webman 2.x（PHP 8.1+）+ ThinkORM 3.0 + SaiAdmin 6.x            |
| AI 集成    | 服务端 AI 代理（可配置模型端点）                               |
| 离线 AI    | 设备端模型部署（webllm）                                       |
| 推送通知   | iOS APNs + Android FCM                                         |
| 存储       | 服务端数据库 + 设备本地加密存储（日记）                        |
| 安全       | HTTPS/TLS、静态加密、参考 HIPAA/GDPR 规范                      |
