治疗支持 App 需求说明（v1.1）
面向医院内小规模部署（≈100 并发），为患者提供日常支持和行为改变辅助。另外一个关键是要英文，我们是面向海外的，可以做成keep那样的app。

1. 背景与目标
   目标：为吸毒（暂时定义为吸毒，可能会有些专业术语我到时候会补充）等行为改变场景提供一个集聊天干预、同伴支持、个人记录、治疗计划与教育资源于一体的移动应用。
   使用场景：院内门诊/随访。医生/治疗师可配置计划，患者在院内及出院后跟随执行。

2. 角色与权限
   患者（默认角色）
   o使用聊天、查看与编辑每日任务、接收通知、发帖与互动（可匿名化昵称）、编辑个人资料、撰写私密日记。
   临床人员/治疗师（AI，医院内部）
   o配置治疗计划（时间线卡片）、下发/审核每日任务模板、查看患者同意后开放的数据仪表（非原文日记，聚合概览）、社区内容审核。

3. 功能需求（按模块）
   3.1 互动聊天（Chat Window）
   说明：与院内部署的AI进行对话干预（全部是AI）；支持文字与语音输入；生成可执行的任务与建议。现在方案的接口是什么样的？
   新增：这里要三个聊天模式框，一个是叫心理医生，一个是叫心理陪伴，一个叫模拟病人（跟心理陪伴一模一样）。心理陪伴使用前先让病人给出一段描述（给点提示可以让AI扮演男友，女友，动物等，并给出要求），然后这部分会传输到服务器上。这两个要能让用户看到介绍，就是使用前有点介绍。
   基础1.文本会话：支持 Markdown 渲染（列表、粗体、链接）、消息撤回（本地 UI 层面）与复制。2.语音视频输入：
   iOS/Android 直接打开麦克风和摄像头，也可以只选择麦克风不开摄像头，这里是实时对话；
   支持长按/点击录音（这里则不是实时对话）；
   AI会返回语音，支持AI返回的语音的播放（也可以纯文本，AI都会返回文本和录音，用户可以选择展开文本或者只听语音，就像微信那样）
   总而言之类似，微信对话那样，可以语音视频通话，可以打字对话，打字对话支持语音输入3.多轮对话上下文保留（可按会话归档）：可能病人会对话几次，比如今天对话了，下周对话了等等之类的，需要保存记录，这个记录患者也可以看到，也要上传到服务器。每次保存的对话记录就命名什么第一次访问第二次访问
   4.AI 任务下发：模型可在对话中返回“任务卡片”（含日期、开始-结束时间、任务内容、提醒方式），任务卡片就是第一次访问结束后会返回这个任务卡片，然后要求编辑进病人的任务日历当中5.心理陪伴：支持离线和在线两种模式，让病人自行选择，离线模式数据会存储在设备本地，模型也是会部署到本地，病人可以自己选择不同的模型下载或者删除。这个同时得兼容安卓和ios两个平台的设备。
   3.2 社区（Community）
   说明：受控的同伴互助区，类似论坛社区体验，要求像keep社区那样。
   帖子：纯文本/图片/链接；标签（求助、经验、复发反思、里程碑等）。
   互动：评论、点赞、收藏、关注标签。
   匿名策略：默认展示昵称 + 可选匿名开关；可一键隐藏历史。
   审核（AI和人）：
   o关键词预审（自杀/自残/违法等敏感词提醒与引导求助），
   o医院人员人工审核通道。
   o举报与封禁机制。
   3.3 个人用户资料（Profile）
   基本信息：昵称、年龄段、性别（可选）、吸毒基线（频率、量级，可选）、触发因素、目标（完全戒断/减少，可选）。同时还有历史记录之类的，包括系统设置什么的。这里分成两种用户一种是病人，一种是医生。医生需要资格认证上传然后审核后才能注册。医生发帖会特别标注一下，给个标记是医生。
   隐私设置：
   o社区可见范围（公开/半公开/匿名）；
   o日记是否可被模型摘要参与进度面板（默认允许，仅聚合）。
   验收：信息编辑后即时生效；敏感字段保存前二次确认。
   3.4 日记（Journal）
   说明：患者用来记录自己的经历或者别的什么，这部分数据保存在用户设备里，不能上传到服务器。两个展示选择：日历那样或者就1，2，3，4那样展示不同的日记
   3.5 时间线卡片（Timeline Card / 治疗计划，奖励分数）
   结构：阶段名称、起止日期、阶段目标、关键任务（支持重复）、复诊节点、评估量表。模型返回结构化任务：{date, start_time, end_time, title, description, reminders:[T-30m, on-time], source: chat|timeline|template}。
   显示：以日历的形式展示，点进去可以砍具体的。
   日历视图：
   o任务卡片展示时间段、优先级、来源；
   o支持拖拽改时间、点击编辑内容；
   o批量完成/跳过/延期。
   患者可对提醒时间做微调。
   奖励分数：可以设计奖励分数，完成一次得到一次分数，可以设计等级系统，分数到了就升级。到了一个等级，会生成回忆录，这个回忆录由我们AI生成，会上传用户的交流历史记录和发帖的之类的信息，然后我们AI生成视频返回回来。然后奖励分数可以到一定程度可以免费跟真人医生预约
   系统通知：
   o与手机原生通知相连（iOS/Android），在 start_time 前可配置 T-5/10/30 分钟提醒；
   o锁屏横幅 + 点击直达任务详情；
   o失败重试与离线队列（网络恢复后下发）。
   验收：
   o能将阶段任务批量写入“每日任务日历”（就是之前AI在访问后返回的任务能编辑到这个日历里面）；
   o变更后同步更新相应提醒。
   o这些后台都能看见
   3.6 教育素材（Material）
   内容类型：文章、视频、音频、小册（PDF/ePub）。
   分类：入门、动机与认知、应对技能、复发预防、家属指南（能够后续动态编辑）。
   可离线缓存、进度记忆（上次看到哪里）。
   用户可以上传自己私人的素材，这里不能上传到公开，只能自己可见
   3.7 娱乐书籍视频游戏（书籍，电影，音乐）
   3.8 真人医生预约模块，像壹心理，预约后跟日历更新
   3.9 账号与登录
   本地注册/登录（手机号或邮箱 + 密码）；
   支持“忘记密码 → 邮箱/手机号重置链接”。
   单端在线限制（可选），支持手动下线其他设备。
   隐私条款与同意书首次登录必读。
