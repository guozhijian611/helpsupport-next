# HelpSupport 项目逻辑结构说明

本文基于当前仓库中的 `readme.md`、`开发需求.md`、`server/plugin/help/config/route.php`、`server/plugin/help/app/*`、`helpsupport-frontend/src/pages`、`saiadmin-artd/src/views/plugin/help` 和 `php webman route:list` 结果整理，用作 review 目录内的快速结构说明。

## 项目定位

HelpSupport 是面向医院内小规模部署的治疗支持 App，覆盖患者端、医生端、后台管理端，用于 AI 陪伴、治疗计划执行、社区互助、教育素材、日记、预约和医生管理。

## 顶层结构

| 路径 | 职责 |
| --- | --- |
| `helpsupport-frontend/` | UniApp / Vue3 患者端与医生端移动应用，包含认证、首页、社区、计划、聊天、素材、预约、我的等页面 |
| `saiadmin-artd/` | SaiAdmin 管理后台前端，包含 HelpSupport 后台 CRUD、SaiAI、短信、用户和系统管理等插件视图 |
| `server/` | Webman / SaiAdmin 后端服务，核心业务插件为 `server/plugin/help` |
| `helpsupport_flutter/` | Flutter 端原型/实现资料和测试截图，当前 review 包复制了 README、静态资源与截图 |
| `Databasse/` | 当前项目 SQL 基线，主文件为 `helpsupport.sql` |
| `Database/` | Phinx 配置、迁移和种子目录 |
| `Doc/`、`OpenAPI/`、`OpenApiYaml/` | 项目文档、接口文档和 OpenAPI/YAML 资料 |
| `医疗支持图片ui/` | 原型设计 UI 图 |

## 后端业务边界

业务后端以 Webman 插件 `plugin/help` 为主，真实路由入口在 `server/plugin/help/config/route.php`。公开接口主要包括注册、登录、协议、运行配置和上传；登录态业务接口统一挂载 `plugin\saiuser\app\middleware\SaiUserCheck`。

主要控制器模块如下：

| 模块 | 控制器 | 主要职责 |
| --- | --- | --- |
| 认证与账号 | `AuthController` | 邮箱/手机验证码、注册、登录、OAuth、个人资料、退出登录 |
| 系统公共能力 | `SystemController`、`IndexController` | 协议、站点信息、运行配置、图片/文件上传 |
| 社区 | `CommunityController` | 帖子、评论、点赞、收藏、关注、举报、医生端审核 |
| 计划与评估 | `TimelineController`、`AssessmentController` | 日历任务、自定义任务、任务完成、评估任务提交 |
| 素材与教育资源 | `MaterialController` | 素材分类、列表、详情、评论、点赞、收藏、私人上传 |
| 日记与回忆录 | `JournalController` | 日记列表、详情、保存、回忆录生成 |
| 浏览历史 | `HistoryController` | 历史记录、同步、清理、删除 |
| 预约 | `AppointmentController` | 患者预约、取消、医生处理、医生列表、可预约时段 |
| AI 聊天 | `ChatConfigController`、`ChatSessionController`、`ChatRecordController`、`ChatConversationController` | 聊天配置、实时配置、会话、消息记录、普通/流式对话 |
| 消息中心 | `MessageController` | 消息列表、未读数、标记已读、全部已读、删除 |
| 医生患者管理 | `DoctorPatientController` | 我的患者、候选患者、患者档案、绑定/解绑、目标与触发因素日志 |
| 医生资源与计划 | `DoctorResourceController`、`DoctorPlanController` | 任务模板、模板文件夹、评估量表、治疗计划配置与医生日历 |

对应业务逻辑集中在 `server/plugin/help/app/logic`，数据模型集中在 `server/plugin/help/app/model/community`。当前模型覆盖社区、素材、聊天、计划、预约、医生患者关系、日记、消息、评估结果、恢复目标和触发因素等表。

## 管理后台结构

HelpSupport 管理端页面集中在 `saiadmin-artd/src/views/plugin/help`，以 `community/*` 目录承载后台 CRUD：

- `appointment`：预约管理。
- `category`：内容分类。
- `comment`：评论管理。
- `config`：聊天/业务配置。
- `material`：素材管理。
- `message`：消息管理。
- `plan`：治疗计划。
- `post`：社区帖子。
- `record`：聊天记录。
- `report`：举报管理。
- `session`：聊天会话。
- `stage`：治疗阶段。
- `tag`：社区标签。
- `task`：日常任务。

后台 API 封装位于 `saiadmin-artd/src/views/plugin/help/api/community`，与上述页面目录一一对应。

## 数据库资料

review 包内数据库资料包含：

- `database/Databasse/helpsupport.sql`：项目 SQL 基线。
- `database/Database/phinx.php`：Phinx 配置。
- `database/Database/migrations/`：后续迁移，目前包含 SaiAI 阿里云实时配置相关迁移。
- `database/plugin-sql/help/install.sql`：HelpSupport 插件安装 SQL。
- `database/plugin-sql/saiadmin/*.sql`：SaiAdmin 基础数据库 SQL。

数据库变更审阅时应同时查看 SQL 基线、插件安装 SQL 和 Phinx 迁移，避免只看其中一个来源。

## UI 与图片资料

review 包内 UI 资料分三类：

- `ui/design/医疗支持图片ui/`：完整原型图，覆盖登录、AI、社区、计划、医生端、素材、预约、我的等页面。

- `ui/assets/`：移动端、Flutter 端和后台使用的静态 UI 图片资源。
- `ui/frontend-static-all/helpsupport-frontend/`：患者端前端静态素材完整归档，包含源码静态素材、平台图标、MLC 站点素材、本地模型配置、页面/manifest 配置，以及当前已有的 App/H5 构建输出 assets/static 文件。
