建议配合以下两份文档一起使用：

- `mlc-android/真机联调清单.md`
- `mlc-android/真机联调记录模板.md`

## 1. 汇总说明

使用建议：

1. 每台设备先单独填写一份“真机联调记录模板”。
2. 再把最终结果汇总到本表。
3. 如同一台设备测试多个基座版本，建议拆成多行记录。

通过状态建议统一为：

- `通过`
- `部分通过`
- `失败`
- `未测`

## 3. 关键观察项

建议特别记录这些横向差异：

- 不同 ABI 是否都能正常识别 `so` 库
- 小内存设备上模型准备时间是否明显变长
- 某些机型是否能识别桥接但 `JSONFFIEngine` 初始化失败
- 同一基座在不同 Android 版本上的表现是否一致
