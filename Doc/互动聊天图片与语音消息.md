# 互动聊天：图片与语音消息

## 目标

普通 Chat Window 在现有文本聊天之上支持：

- 从相册一次选择最多 9 张图片，先作为草稿预览，再和用户提示词一起发送给 AI。
- 长按录音，松开后发送；也可点击开始、再次点击结束并发送。
- 普通语音消息是“录完再发”，不复用实时音视频 WebSocket 通话链路。
- AI 回复始终保留文本，后端同时尝试合成语音；用户可播放语音，也可展开/收起文本。
- 语音服务不可用时不丢失 AI 文本回复，客户端按纯文本消息展示。

## 接口

### 上传聊天媒体

`POST /app/help/chat/media/upload`

`multipart/form-data` 参数：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `file` | 是 | 图片或语音文件 |
| `media_type` | 是 | `image` 或 `voice` |

限制：

- 图片：`jpg/jpeg/png/webp/gif`，最大 10MB。
- 语音：`m4a/aac/mp3/wav/ogg/webm`，最大 20MB。

成功响应 `data` 核心字段：

```json
{
  "attachment_id": 123,
  "media_type": "voice",
  "url": "/storage/20260815/example.m4a",
  "mime_type": "audio/mp4",
  "size_byte": 204800
}
```

### 发送聊天消息

`POST /app/help/chat/send/stream` 和 `POST /app/help/chat/send` 共用以下契约：

| 字段 | 说明 |
| --- | --- |
| `session_id` | 会话 ID |
| `chat_mode` | 聊天模式 |
| `content` | 文本或图片说明；发图片时必须填写，不再自动补默认句 |
| `content_type` | `text/image/voice` |
| `attachment_id` | 单张图片或语音的附件 ID |
| `attachment_ids` | 多张图片的附件 ID 列表，最多 9 张；可与 `attachment_id` 同时传 |
| `duration_seconds` | 语音时长，1–300 秒 |

聊天记录使用已有 `ext` JSON 保存媒体元数据，不新增数据表：

```json
{
  "attachment_id": 123,
  "attachment_ids": [123, 124],
  "media_url": "/storage/20260815/example.jpg",
  "media_urls": ["/storage/20260815/example.jpg", "/storage/20260815/b.jpg"],
  "media_mime_type": "image/jpeg",
  "duration_seconds": 8,
  "transcript": "这是用户语音的转写文本",
  "audio_url": "/storage/chat-ai/202608/response.mp3",
  "audio_mime_type": "audio/mpeg",
  "speech_status": "ready"
}
```

`media_*` 用于用户上传的媒体，`audio_*` 用于 AI 回复语音。AI 回复的 `content` 始终是完整文本。

## AI 语音配置

转写和合成复用当前聊天选中的 SaiAI OpenAI 兼容 API Key/Base URL，可通过环境变量调整模型：

| 环境变量 | 默认值 |
| --- | --- |
| `SAIAI_SPEECH_CONFIG_ID` | `0`，复用当前聊天模型配置；非 0 时固定使用指定 SaiAI 配置 |
| `SAIAI_TRANSCRIPTION_MODEL` | `whisper-1` |
| `SAIAI_SPEECH_MODEL` | `gpt-4o-mini-tts` |
| `SAIAI_SPEECH_VOICE` | `alloy` |

当前选中的上游网关需同时支持 `/v1/audio/transcriptions` 和 `/v1/audio/speech`。转写失败时语音消息不会发给 AI；合成失败时保留已生成的 AI 文本。

## 客户端交互

- 文本输入栏左侧增加图片按钮，支持相册多选；选中后先出现在输入框上方预览，可单张删除。
- 有待发图片时必须先写提示词，再点发送；不会选完立刻发出。
- 语音模式显示“点击或按住录音”；录音中可再次点击或松开发送。
- 用户语音气泡点击即播放/暂停，展开后显示后端转写文本。
- AI 语音气泡提供播放/暂停和文本展开两个独立操作。
- 图片气泡按一张大图或多图网格显示真实缩略图，并展示用户提示词。
- 浅色/深色主题、中英文案和现有字体缩放继续由现有主题与 `_t` 本地化链路控制。

## 验收清单

1. 上传非允许类型、超限文件时接口返回明确业务错误。
2. 可选多张图片，选完不发送；写完说明后图片与提示词一起发出，重新加载后多图仍可显示。
3. 长按和点击两种录音方式都会生成真实音频、上传、转写并进入 AI 对话。
4. 用户与 AI 语音气泡可播放/暂停，文本可展开/收起。
5. 退出再进入会话后，图片 URL、语音 URL、时长和转写文本仍完整。
6. 语音合成上游失败时，AI 文本仍能正常展示。
